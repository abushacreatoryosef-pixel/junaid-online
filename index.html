Beeksisa Fi Ergaa Yadataa Junaid

Namoonni gargaarsa mallaqa barbaaddan kan hattootaan fi maqaa kootiin saamamaa turtan, kan gargaarsa dhaabbata kiyyaa barbaaddan:

"Ani dhugumaatti isin deeggaruun barbaada. Deeggarsa kana argachuuf mallaqa dhaabbata kiyya irraa gaali wagga tokkoo arjoomeen jira. Marree gargaarsa kana argachuuf galmee karaa Agency kiyya magaalaa Finfinnee argamuun isin galmeessuun mallaqa isin barbaachisu isin deeggara."

Kaffaltii galmee fi sharafaa mallaqaa qarshii 1852 qofadha. Kana kaffalun sharafachu kan dandeessan isin deeggaruuf jira!
